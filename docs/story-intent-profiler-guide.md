# 剧情投射式标签诊断说明

## 1. 文档目的

本文档定义原创灵感页的 Story Intent Profiler。它不是传统问卷，也不是让用户直接点标签，而是通过剧情情境、情绪偏好、角色投射、对手类型和下一集钩子，反推用户真正想写的短剧方向，并回填到现有标签体系。

当前版本优先校准漫剧入口：受众只保留“男频 / 女频”，不新增年龄受众；前台题面要像真实剧情选择，不把内部高频模板词直接展示给用户。

---

## 2. 命名

- 中文正式名：剧情投射式标签诊断
- 前台用户名：创作方向测试 / 30 秒测出你的短剧方向
- 技术名：Story Intent Profiler
- 模块名建议：`story_intent_profiler` 或 `projective_tag_router`

## 3. 方法原则

### 3.1 投射式选择

不要直接问：

```text
你要现代职场、甜宠、玄幻哪种？
```

要问：

```text
下面哪个开场你最想继续看？
```

用户选择剧情刺激，后台再换算成受众、题材、核心设定、风格元素。

### 3.2 强迫取舍

需要让用户做取舍：

- 最想看的
- 最不想看的
- 如果必须删掉一个元素，删哪个

这样可以区分主标签和次标签。

### 3.3 自适应追问

如果两个方向分数接近，就补一道追问。

示例：

```text
你更想让主要冲突发生在哪里？
A. 宗门、秘境、城池、战场
B. 豪门、公司、婚姻、家庭
```

### 3.4 多标签评分

每个选项同时影响四类标签：

- audiences
- genres
- coreHooks
- styleTags

示例：

```text
少年被逐出师门，在禁地捡到一枚会说话的旧铃铛。
```

可能加权为：

- 目标受众：男频 +3，女频 +1
- 题材类型：玄幻 +5，修仙 +4，仙侠 +2
- 核心设定：传承觉醒 +4，人物逆袭 +3，小人物 +3
- 风格元素：热血成长 +4，反转驱动 +3，特效 +3

## 5. 目标受众

当前仓库受众标签为：

```tsx
AUDIENCE_OPTIONS = ["男频", "女频"]
```

当前阶段结论：漫剧入口只保留男频、女频，不新增年龄受众。

漫剧方向的用户投射通过这些维度判断：

- 主角投射：被低估后翻盘、隐藏身份、强者重开、改写命运、小人物破局
- 情绪回报：被轻视后证明自己、身份公开、强强互救、规则破局、荒诞反转
- 世界偏好：玄幻修仙、规则怪谈、末世灾变、赛博机甲、异界冒险
- 付费钩子：实力暴露、身份公开、灾变降临、规则漏洞、关系选择、对手反算

以下方向不进入当前漫剧默认题库：

- 家庭赡养
- 子女分家产
- 养老冲突
- 晚年翻身
- 中老年婚姻修复

## 6. 题面文案要求

前台问题和选项必须使用具象剧情，不要把内部标签直接当成用户选项。

不推荐的题面风格：

```text
请选择你想要的男频升级流方向。
```

推荐的题面风格：

```text
少年被逐出师门，在禁地捡到一枚会说话的旧铃铛。
```

原则：

- 题面要有画面，不要只有标签
- 题面要像剧情开场，不要像参数表
- 用户看得懂，后台再算标签
- 技术词、模板词、内部分类词不要高频出现在问题中

## 7. 漫剧五问结构

**前端实现说明**：当前前端 MVP 使用精选子集（每步 4 个选项），但五步语义必须与文档保持一致。受众（男频/女频）不再作为第 1 步直接选择，而是由后台根据五步投射结果反推。

### 7.1 第 1 问：最想看的开场

目的：识别第一反应最强的剧情刺激。

题目：

```text
下面哪个开场你最想继续看？
```

选项与映射：

- 少年被逐出师门，在禁地捡到一枚会说话的旧铃铛。
  - 映射：男频、玄幻、修仙、仙侠、传承觉醒、人物逆袭、小人物、热血成长、反转驱动、特效。
- 落难女帝醒来成了小门派打杂少女，只有她记得前朝密诏。
  - 映射：女频、仙侠、古代、架空历史、女帝、身份反转、强强联合、情绪驱动、甜宠恋爱、反转驱动。
- 午夜客栈每天重置，墙上的第七条规矩被人悄悄划掉。
  - 映射：男频、女频、规则怪谈、悬疑、灵异、无限游戏、脑洞流、紧张悬疑、惊悚诡秘、悬念驱动。
- 天灾倒计时前，主角把钱全花在别人看不懂的物资上。
  - 映射：男频、末世、天灾、废土、重生信息差、求生种田、经营势力、人物逆袭、反转驱动、强势碾压。
- 全村祭典前夜，主角看见山神像流下黑色眼泪。
  - 映射：男频、女频、民俗怪谈、灵异、乡村、神话、脑洞流、紧张悬疑、诡秘、反转驱动。

### 7.2 第 2 问：最上头的情绪刺激

目的：识别用户真正想要的情绪回报。

题目：

```text
哪一种情节最容易让你上头？
```

选项：

- 被所有人轻视的人，关键时刻拿出真正本事。
- 藏了很久的身份突然被发现，全场态度瞬间反转。
- 两个互不信任的人，一次次在危险里救下对方。
- 主角看懂别人都忽略的规则，找到了唯一活路。
- 一件看似荒唐的小事，把原本严肃的大局彻底带偏。

### 7.3 第 3 问：最想代入的主角

目的：识别主角投射对象。

题目：

```text
你更想让主角是哪种人？
```

选项：

- 一开始被所有人看轻，但始终憋着一口气的人。
- 身份很特殊，却因为某个原因暂时不能暴露的人。
- 曾经站得很高，如今失去一切后重新夺回主动权的人。
- 明知道结局不利，偏要亲手改写命运的人。
- 看似普通，却总能用非常规办法把局面盘活的人。

### 7.4 第 4 问：最想反转的对手

目的：通过对手类型识别题材偏好。

题目：

```text
你最想看哪种对手被反转？
```

选项：

- 仗着地位打压主角的师门长辈或上位者。
- 满口正义，背地里抢走别人机会的人。
- 自以为掌控全局，把所有人都当棋子的人。
- 制定规矩困住别人，自己却躲在规矩背后的人。
- 看不起主角出身和能力，最后被当众反转的人。

### 7.5 第 5 问：最愿意付费的下一集钩子

目的：识别付费点和主线推进方式。

题目：

```text
如果这是一部漫剧，你最愿意为哪种下一集付费？
```

选项：

- 主角真正的实力马上要暴露。
- 被隐藏的身份马上要公开。
- 女主、师尊或盟友马上要做出关键选择。
- 所有人都害怕的规矩马上要被打破。
- 第一场真正的灾变马上要降临。
- 对手马上要发现自己才是被反算的人。

## 8. 漫剧受众判断规则

男频倾向通常来自：

- 升级、战力、势力、资源争夺
- 强者回归、经营扩张、末世求生
- 对手压迫越强，主角反击越强
- 世界观扩张、战斗升级、阵营升级

女频倾向通常来自：

- 女帝、圣女、师妹、仙子、大女主
- 身份反转、关系拉扯、强强互救
- 被背叛后清醒反击
- 关系张力、情绪选择、身份公开后的关系重排

男频 + 女频兼容方向：

- 规则怪谈
- 民俗怪谈
- 沙雕修仙
- 反套路
- 悬疑破局
- 群像冒险
- 强设定脑洞

## 9. 标签评分矩阵结构


## 10. 评分规则

### 10.1 基础累计

每个用户选择都会对四类标签加权：audiences、genres、coreHooks、styleTags。每类标签分别独立累计。

### 10.2 Best-Worst 加权

推荐规则：

- best：权重 × 1.0
- secondary：权重 × 0.6
- worst：权重 × -0.8

### 10.3 锁定标签

如果某个选项含 `locks`，则这些标签进入 `lockedTags`。锁定标签输出时优先保留，后续生成不得轻易覆盖。

### 10.4 排除标签

如果某个选项含 `excludes`，对应标签进入 `excludedTags`。输出时不自动补入这些标签。

### 10.5 置信度

```text
confidence = 第一名分数 / 前三名分数总和
```

简化判断：

- 0.75 以上：高置信
- 0.45 - 0.75：中置信
- 0.45 以下：低置信

低置信时不强行出结果，进入自适应追问。

## 11. 互斥规则

### 11.1 现实题材规则

如果用户选择现代职场、职场、公司场景、专业能力、商业能力、现实主义，默认不自动混入玄幻、修仙、仙侠、异世界、魔法世界、星际、机甲。

### 11.2 漫剧幻想规则

如果用户选择宗门、禁地、神像、秘境、重置空间、异界大陆、机甲、星际、天灾、民俗怪谈等方向，默认应优先保持强设定和画面奇观，不要自动混入现实家庭伦理或职场写实冲突。

### 11.3 豪门情感规则

豪门可与家庭伦理、婚姻情感、真假千金、豪门恩怨、先婚后爱、追妻火葬场、替嫁逼婚、身份揭露、财力暴露共存，但不应默认混入玄幻、修仙、星际、机甲、无限游戏。

## 13. 与原创系统的衔接

测试完成后，结果回填到原创灵感页：

- 目标受众：`audiences`
- 题材类型：`genres`
- 核心设定：`coreHooks`
- 风格元素：`styleTags`

还应生成 `userPremise`，承接用户测试结果与自由输入。

推荐格式：

```text
用户通过创作方向测试选择：
- 最想看的开场：...
- 最上头的情绪刺激：...
- 最想代入的主角：...
- 最想反转的对手：...
- 最愿意付费的钩子：...

系统总结：...
```

用户自由输入拥有最高优先级。如果用户明确写了“现代职场”，不得因为测试选项自动改为玄幻、异世界、修仙；如果用户明确写了“玄幻修仙”，不得自动偏移到家庭伦理、婚姻现实、职场写实。

## 15. 验收标准

### 15.1 文档阶段验收

- 文档存在
- 文档包含系统命名
- 文档包含方法来源
- 文档包含漫剧标签清单
- 文档包含真人短剧标签清单
- 文档明确受众仍为男频/女频
- 文档包含 5 问结构
- 文档包含漫剧专项设计
- 文档包含评分矩阵结构
- 文档包含互斥规则
- 文档包含输出 JSON
- 文档说明与原创系统的衔接方式
- 前台问题示例不出现高频模板词

### 15.2 功能阶段验收

- 用户完成 5 问后能得到四类标签
- 真人短剧模式优先使用 `LIVE_ACTION_PRESET`
- 漫剧模式优先使用 `AI_SHORT_DRAMA_PRESET`
- 漫剧题库只在受众层输出男频/女频
- 漫剧问题题面不直接暴露高频模板词
- 现代职场不会被错误引导到玄幻、修仙、异世界
- 玄幻修仙不会被错误引导到家庭伦理、婚姻现实、职场写实
- 用户自由输入仍然拥有最高优先级
- 低置信时出现追问，而不是强行输出标签

---

## 16. 最终结论

Story Intent Profiler 应作为 1TiStory 原创入口的上游意图识别层。

它的价值不是替代标签选择，而是降低用户表达成本：用户只需要选择自己想看的剧情刺激，后台就能反推出更准确的短剧创作标签。

当前漫剧入口应优先围绕男频/女频、强设定、角色投射、情绪回报、付费钩子进行判断，不新增年龄受众，不把现实养老、子女财产争夺等议题混入默认题库。

后续实现时，应把文档中的题面示例转换为配置化问题，并保持一个原则：前台说人话，后台算标签。
